# Scanned-Document-Extraction
Extractor extracts all the data from a scanned pdf document. It separates all pages from pdf, checks the presence of tabular or text data, extracts data from each page and saves into different text files and csv files.


code_document_extraction.py - Read entire document, separates each pages and extracts data from each page.

code_page_extraction.py - Read single page as image and extracts data
